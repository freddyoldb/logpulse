# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within LogPulse, please do not open a public issue. Send an email directly to the maintainer or open a private security advisory via GitHub. 

All security vulnerabilities will be addressed promptly.
